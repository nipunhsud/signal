# Environment Presets

Copy any of these `.env` configurations to quickly switch scanning modes.

---

## 1. **Blue Chip Only (DOW 30 - 30 stocks)**

```bash
# Breakout Agent
ASSETS_FILE_PATH=./scripts/scanner-lists/dow30-tradingview-import.txt
DATA_SOURCE=ibkr
CRON_SCHEDULE=0 * * * *
SCAN_ASSETS=

# Trading Agent
MAX_POSITION_SIZE=95
STOP_LOSS_PERCENT=0.02
TRADE_CRON_SCHEDULE=*/5 * * * *

# IB Gateway
IBKR_BASE_URL=https://localhost:5000
```

**When to use:** Testing, small portfolio, low-frequency scanning (1x/hour)


**Instance 2 (.env.tier-2):**
```bash

```

**...**

**Instance 60 (.env.tier-60):**
```bash
ASSETS_TIER=60
# ... rest same
```

**Docker Compose Example:**
```yaml
version: '3'
services:
  breakout-1:
    image: signal-forge:latest
    env_file: .env.tier-1
    
  breakout-2:
    image: signal-forge:latest
    env_file: .env.tier-2
    
  # ... repeat for 60 instances
```

**When to use:** Full NYSE scan (3,000 stocks), parallel scanning at scale

## 6. **Custom List (Your Own CSV)**

Create a file: `scripts/scanner-lists/my-watchlist.txt`

Format (TradingView):
```
NYSE:AAPL,NYSE:MSFT,NYSE:GOOGL,NASDAQ:AMZN,NASDAQ:TSLA
```

Then in `.env`:
```bash
ASSETS_FILE_PATH=./scripts/scanner-lists/my-watchlist.txt
DATA_SOURCE=ibkr
CRON_SCHEDULE=0 * * * *
```

## How to Switch Presets

```bash
# View current config
cat .env | grep -E "ASSETS|DATA_SOURCE|CRON"

# Switch to DOW30 preset
cp .env .env.backup
cat > .env << 'EOF'
ASSETS_FILE_PATH=./scripts/scanner-lists/dow30-tradingview-import.txt
ASSETS_MODE=
ASSETS_TIER=
DATA_SOURCE=ibkr
CRON_SCHEDULE=0 * * * *
MAX_POSITION_SIZE=95
STOP_LOSS_PERCENT=0.02
TRADE_CRON_SCHEDULE=*/5 * * * *
IBKR_BASE_URL=https://localhost:5000
GEMINI_API_KEY=your-key
EMAIL_SERVICE=gmail
EMAIL_USER=your-email
EMAIL_PASS=your-app-password
ALERT_EMAIL=alerts@example.com
DATABASE_URL=postgresql://...
EOF

# Restart agents
npm run dev
```

## API Rate Limit Guidance

| List | Scanning Full List | Recommended Approach |
|------|-------------------|----------------------|
| DOW 30 | 1 instance, 30min | Direct (no tiering) |
| NASDAQ-100 | 1 instance, 1-2h | Tier or subset |
| NYSE (3,000) | 50-100 instances, 30min | Tier with SIZE=50 (60 instances) |
| NASDAQ (3,400) | 34-68 instances, 30min | Tier with SIZE=100 (34 instances) |
| NSE 500 | 10 instances, 30min | Tier with SIZE=50 (10 instances) |

Interactive Brokers limits: ~1000 requests/second per account.
